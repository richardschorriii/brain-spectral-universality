## Key Results
- **Spectral universality:** r = 0.9852 across resting-state conditions
- **Subjects:** 10 (PhysioNet Motor Imagery dataset)
- **Statistical significance:** All 5 spectral bands pass Bonferroni-corrected threshold
- **Topology independence:** Consistent across connectivity methods and rescaling parameters
