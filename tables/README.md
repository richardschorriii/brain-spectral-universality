# Tables

Supplementary data tables in CSV format.

## Structure

```
tables/
└── supplementary/   # Tables S1–S4
```

## Paper 1 — Spectral Universality in Resting-State Brain Networks

## Adding future papers

Create subdirectories per paper:
```
tables/supplementary/paper-02/
tables/supplementary/paper-03/
```
Or use the corresponding paper branch. See `BRANCH_STRATEGY.md` in the root.
