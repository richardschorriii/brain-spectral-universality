# Supplementary Tables — Paper 1

All tables correspond to Schorr (2026), *Spectral Universality in Resting-State Brain Networks*.

## Contents

| File | Table | Description |
|------|-------|-------------|
| `Table_S1_Bonferroni_Correction.csv` | S1 | Per-band correlations with Bonferroni-corrected significance (all 5 bands survive) |
| `Table_S2_EyesOpen_vs_EyesClosed.csv` | S2 | Eyes-open (r=0.9555) vs eyes-closed (r=0.9852) universality comparison |
| `Table_S3_Rescaling_Parameter_Comparison.csv` | S3 | λ₂ vs λ_max vs mean eigenvalue vs spectral radius — ranked by universality |
| `Table_S4_Connectivity_Methods_Comparison.csv` | S4 | Pearson vs PLV vs Coherence connectivity methods — all robust |

## Key Result

λ₂ rescaling achieves highest universality (r = 0.9852) across all tested alternatives (Table S3), confirming the PMIR prediction that algebraic connectivity is the natural rescaling parameter.
